# Agent instructions

This repo is an Obsidian vault template for product decisions. The vault lives in `vault/`.

- The rules are in `vault/_rules.md`. Follow them for every edit.
- To file new input (meeting notes, customer calls, research), follow `.claude/skills/vault-intake/SKILL.md`.
- To run the monthly check, follow `.claude/skills/vault-gate/SKILL.md`.

Never invent goals, facts, owners, or dates. Never delete a note. Overturned decisions are marked `superseded`, not removed.
